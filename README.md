# Enterprise Decision Intelligence Platform

## Overview

Enterprise Decision Intelligence Platform (EDIP) is an AI-powered business analytics platform that combines Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), Machine Learning, and Data Analytics to help organizations make data-driven decisions.

## Features

- AI-powered data analysis
- Automated EDA
- Business dashboards
- Natural language querying
- Forecasting
- Executive report generation
- Multi-Agent AI workflow

- Python
- FastAPI
- React
- PostgreSQL
- LangGraph

- FAISS
- Plotly
- XGBoost
